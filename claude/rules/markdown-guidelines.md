# Markdown Guidelines

## Tables

- Only edit Markdown tables that are not automatically generated by a tool like `terraform-docs`.
- All pipe characters (`|`) must be vertically aligned across every row of the table.
- Pad cell contents with trailing spaces so each `|` sits in the same column position throughout.
- Place a single space between every `|` and the adjacent content.
- The header separator row uses hyphens (`-`) filling the full inner width of each column, with a single space between the `|` and the hyphens, for example:

```markdown
| Output   | Description     |
| -------- | --------------- |
| `url`    | The URL         |
| `number` | The number      |
| `branch` | The head branch |
```
